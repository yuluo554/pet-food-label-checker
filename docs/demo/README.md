## 一处审计扫不到的泄漏（M5 修掉）

"关于"页会把**数据目录的绝对路径**打在界面上。真实用户看到自己的路径没问题，
但**我们生成素材时会把本机工作根路径烤进 PNG**——而脱敏审计按扩展名把 PNG
当二进制跳过（`EXCLUDE_SUFFIXES`），**完全看不到它**。于是本机路径会随公开素材入仓，
且与 M4 那条坑同族（`--tracked` 看不到未 `git add` 的新文件）：**绿 ≠ 验过了**。

处置：生成器在**产素材那一步**把仓库根/数据目录替换成中性占位符，
并跑硬断言（`_assert_no_local_paths`）——在源头守，而不是等事后审计（它根本看不到）。
断言判据落在"**盘符路径起始位置**"（`(?<![\w])[A-Za-z]:[\\/]`），
刻意避开 `https://`（参数来源块里 URL 很多，用 `":/"` 当判据会大面积误报）。
